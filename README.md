# 🚢 Titanic Survival Prediction Using Machine Learning

## 📌 Project Overview
This project focuses on predicting Titanic passenger survival using Machine Learning classification algorithms. It uses passenger information such as gender, age, number of siblings, parents/children aboard, and ticket fare to predict whether a passenger survived or not.

## 🎯 Project Objectives
- Perform data preprocessing and cleaning.
- Handle missing values.
- Apply Label Encoding for categorical data.
- Perform Exploratory Data Analysis (EDA).
- Train Machine Learning classification models.
- Predict passenger survival.
- Evaluate model performance using classification metrics.

## 📂 Dataset Information
The dataset contains passenger details with the following features:

| Feature | Description |
|---|---|
| PassengerId | Unique passenger ID |
| Pclass | Passenger class |
| Sex | Gender |
| Age | Passenger age |
| SibSp | Siblings or spouses aboard |
| Parch | Parents or children aboard |
| Fare | Ticket fare |
| Survived | Survival status (Target) |

## 🤖 Machine Learning Algorithms
1. Logistic Regression
2. Bernoulli Naive Bayes

## ⚙️ Project Workflow
1. Import required Python libraries.
2. Upload and load the Titanic dataset.
3. Perform data cleaning.
4. Check and remove duplicate records.
5. Visualize outliers using a Box Plot.
6. Handle missing values using median imputation.
7. Encode categorical features.
8. Split the dataset into training and testing sets.
9. Train Logistic Regression and Bernoulli Naive Bayes models.
10. Predict passenger survival.
11. Evaluate model performance.

## 📊 Model Evaluation
The project uses the following evaluation metrics:

- Accuracy Score
- Precision Score
- Recall Score
- F1 Score
- Confusion Matrix
